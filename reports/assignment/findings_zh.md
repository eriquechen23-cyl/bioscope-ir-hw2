## RQ1 / RQ2：是否符合 Zipf？指數是多少？
主要條件 B：slope=-1.2982、intercept=5.1468、k=1.2982、R²=0.9708、log10 RMSE=0.0975。

## RQ3：前處理影響
移除停用詞使 token 減少 32.4%，k 降為 1.2414。再 stemming 保持 token 總數、詞彙降到 7,815，k 變為 1.3487。詞彙較少不等於檢索品質較好。

## RQ4：CF / DF / IDF
CF 是整體詞次，DF 是文件數。同篇重複增加 CF，不一定增加 DF。GLP-1 出現於 929 篇，IDF=0.074；semaglutide 出現於 85 篇，IDF=2.465。主題重要性與區辨力不同。

## RQ5 / Final Challenge
少數詞占很多詞次、很多罕見詞增加詞典項目，能引導停用詞、倒排索引、壓縮與 TF-IDF 設計。實際效益仍需檢索任務與索引大小評估；本實驗沒有證明效能提升，也沒有做兩領域 Optional Challenge。
高 R² 不足以證明 power law，還要看 residuals、同頻平台、區間與替代模型。以上為原始 1,000 篇固定結果；網站選取子集時以即時計算表格為準。
